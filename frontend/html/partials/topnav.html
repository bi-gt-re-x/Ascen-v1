{# The app's top navigation bar. One copy, included by every signed-in page (dashboard, calendar, growth, goals) so a link only ever has to be added once. The landing page keeps its own public header, because it is what signed-out visitors see. The active pill is worked out from request.path rather than passed in by each page, so including the partial is the whole integration. The bar is fixed. Every page that includes it also carries the `has-topnav` class on , which src/styles/navbar.css uses to push the page's content clear of the bar. It also collapses, from the chevron at its right end. Collapsing sets `nav-collapsed` on , which shrinks --topnav-h — and because every page sizes itself off that variable, the page under it grows into the space on its own. #} {# Written before the bar so the collapsed height is in place for the first paint: setting it from the deferred script would show a full-height bar for a frame and then snap it shut. #}
