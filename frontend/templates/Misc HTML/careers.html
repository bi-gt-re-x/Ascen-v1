Careers

Ascen is a small, focused project on a mission to make consistent effort feel rewarding. We're not a big company — and that's the point. Everyone who contributes shapes the product directly.

Open Roles

Frontend Contributor

Remote · Volunteer / Open Source

Help polish the dashboard, calendar, and growth charts. You care about clean HTML/CSS/JavaScript, small bundle sizes, and interfaces that stay out of the user's way.

Backend Contributor

Remote · Volunteer / Open Source

Work on the Flask backend — routes, the JSON datastore, and the XP/streak engine. Bonus points if you enjoy writing code that's simple enough to read in one sitting.

Design & UX

Remote · Volunteer / Open Source

Champion "Simplicity First." Sweat the details of spacing, typography, and dark mode so studying with Ascen feels calm instead of cluttered.

Why Work On Ascen?

🛠 Real Ownership

Small team, no bureaucracy — your ideas ship and your name is on them.

📚 Built for Learners

The product is a study tool; the codebase is a study tool too. Great for growing your skills.

🌱 Users First

Every feature is tested in real study sessions before it ships.

⏰ Flexible

Contribute when it fits your schedule — consistency over intensity applies here too.

How to Apply

Send a short note about yourself and what you'd like to work on to careers@ascen.app, or open a pull request on the project's repository — the best application is a contribution.

Don't see a role that fits? Write in anyway. If you care about helping people build better habits, we want to hear from you.
